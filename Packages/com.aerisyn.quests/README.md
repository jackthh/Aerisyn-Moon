# Aerisyn Quests (`com.aerisyn.quests`)

Quest definitions, progress tracking, and reward hooks as a standalone UPM package.

**Unity:** 2022.3+

## Install

Package Manager → **+ → Add package from git URL…**

```text
https://github.com/jackthh/Aerisyn-Moon.git?path=/Packages/com.aerisyn.quests
```

## Layout

| Folder | Purpose |
|---|---|
| `Runtime/` | Player / runtime API (`Aerisyn.Quests`) |
| `Editor/` | Editor tooling (`Aerisyn.Quests.Editor`) |
| `Samples~/` | Optional samples (not imported unless selected) |

## Status

`0.1.0` scaffold. Public API will land as the Quests system is ported in.
